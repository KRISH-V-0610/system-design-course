# sysdesign-notes

My write-ups for the 28-week system design curriculum. One file per week.
Rule: if I can't explain a concept in my own words here without looking it up,
I don't actually know it yet.

## How I use this repo

- Each week's file follows the template in `weeks/_template.md`.
- Deliverables/labs go in their own project repos (`perf-lab`, `linkforge`, etc.)
  — this repo is for the *written understanding*, not the code.
- Design drill write-ups (starting Week 5) go in `drills/`.
